# Презентация из обычного текста

- Один файл Markdown — и готовы **PDF, PPTX или картинки**
- Заголовок строкой с решёткой — это новый слайд
- Пункты — обычные тире

# Как устроен этот файл

- Строка, начатая с решётки — заголовок слайда
- Строка, начатая с тире — пункт списка
- Две звёздочки вокруг слова — **цветной акцент**

# Что настраивается в браузере

- Шрифт заголовков и шрифт текста — **по отдельности**
- Цвета, градиенты, размер и ширина текста
- Фон: свой файл или один из готовых

# Два размера под разные площадки

- **Горизонтальный** 1920×1080 — экран, Zoom, YouTube
- **Вертикальный** 1080×1920 — Reels, Shorts, сторис
- Один и тот же текст, две разные презентации

# Что делать дальше

- Замените этот текст своим
- Нажмите **«Сгенерировать»**
- Скачайте готовый файл
