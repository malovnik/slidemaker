Форматы файлов

                
Принимаются файлы: .md, .markdown, .txt

            


            

                
Структура документа

                
    
                    
  • # Заголовок — создаёт новый слайд
    • 
                    
  • ## Подзаголовок — тоже создаёт слайд (используйте для разделов)
    • 
                    
  • - Пункт списка — добавляет текст на слайд
    • 
                    
  • Обычный текст без маркеров игнорируется
    • 
                

            


            

                
Рекомендации по контенту

                
    
                    
  • Заголовок — краткий, ёмкий тезис (5-7 слов). Это ключевая мысль для зрителя
    • 
                    
  • Пунктов — не более 3-4 на слайд, только самое важное
    • 
                    
  • Подзаголовок ## — используйте для логических разделов или когда нужен слайд без списка
    •

Промпт для ИИ

                
Скопируйте и вставьте в ChatGPT/Claude вместе со сценарием:

                

                    
                    
Преобразуй этот сценарий видео в Markdown файл для презентации.

Правила форматирования:
1. Каждый смысловой блок = один слайд с заголовком #
2. Заголовок — краткий тезис из 5-7 слов, суть мысли для зрителя
3. Под заголовком 2-4 пункта через "- " (тире и пробел)
4. Пункты — только ключевые факты, цифры, действия
5. Используй ## для разделов или слайдов без списка
6. Никакого лишнего текста, только # заголовки и - пункты

Пример структуры:
# Почему это важно
- Первый ключевой факт
- Второй ключевой факт
- Призыв к действию

## Следующий раздел
- Пункт раздела

Сценарий:
[ВСТАВЬ СЦЕНАРИЙ СЮДА]
