# Инструкция для ИИ-помощника

Этот файл написан для агента (Claude Code, Codex CLI, Cursor, Gemini CLI и подобных), которого попросили развернуть Slidemaker на компьютере пользователя. Человеку читать не обязательно — ему адресован README.md.

## Задача

Установить и запустить локальное веб-приложение, открыть его в браузере, сообщить пользователю адрес. Пользователь, скорее всего, не программист: не объясняйте ему устройство виртуального окружения, просто доведите до работающего результата.

## Что это за проект

Flask-приложение. Превращает markdown в презентации PDF / PPTX / JPG-архив. Точка входа для локального запуска — `main.py`, для сервера — `wsgi.py` (gunicorn). Ядро конвертации — `md_to_slides.py`, веб-слой — `web/`.

## Порядок действий

1. **Проверьте Python.** Нужен 3.9+. `python3 --version` (Windows: `python --version`). Нет — поставьте: macOS `brew install python@3.12`, Linux `apt install python3 python3-venv`, Windows — направьте пользователя на python.org, установщик требует ручного подтверждения.

2. **Получите код.** `git clone https://github.com/malovnik/slidemaker.git` в удобную папку (`~/Documents` или аналог). Если проект уже скачан — используйте существующую папку, не клонируйте второй раз.

3. **Создайте окружение и поставьте зависимости** внутри папки проекта:
   ```bash
   python3 -m venv .venv
   .venv/bin/pip install -r requirements.txt
   ```
   Windows: `python -m venv .venv` и `.venv\Scripts\pip install -r requirements.txt`.
   Если в системе есть `uv`, быстрее: `uv venv && uv pip install -r requirements.txt`.

4. **Проверьте, что всё работает, до запуска сервера.** Прогоните генерацию на образце и убедитесь, что получился непустой PDF:
   ```bash
   .venv/bin/python -c "
   import io, base64
   from web.app import create_app
   c = create_app().test_client()
   md = open('example.md','rb').read()
   r = c.post('/api/generate', data={'markdown': (io.BytesIO(md), 'example.md'), 'export_format': 'pdf'}, content_type='multipart/form-data')
   j = r.get_json()
   assert j.get('success'), j
   print('OK', len(base64.b64decode(j['file_base64'])), 'байт')
   "
   ```
   Команду запускайте из корня проекта. Ответ вида `OK 168000 байт` означает, что генерация исправна.

5. **Запустите сервер.** `.venv/bin/python main.py` — фоновым процессом, чтобы не блокировать сессию. Приложение поднимется на `http://127.0.0.1:5000` и само откроет браузер. Порт занят — задайте другой: `PORT=5001 .venv/bin/python main.py`.

6. **Сообщите пользователю** адрес, по которому открывать, и как остановить (`Ctrl+C` в терминале с процессом). Кратко скажите, что нужно перетащить свой `.md` файл в левое окно, а образец лежит в `example.md`.

## Необязательное — делайте только если пользователь попросил

- **Экспорт в JPG** требует Poppler: macOS `brew install poppler`, Linux `apt install poppler-utils`. PDF и PPTX работают без него, поэтому не ставьте Poppler молча — это установка системного пакета.
- **Кнопка «AI Подготовка»** требует `OPENAI_API_KEY` в файле `.env`. Ключ есть только у пользователя. Никогда не вписывайте туда ключи из своей памяти, других проектов или переменных окружения хоста.

## Чего не делать

- Не запускайте с `PIN_CODE` — на локальной машине вход не нужен, а пин собьёт пользователя с толку.
- Не открывайте приложение наружу (`HOST=0.0.0.0`, туннели, публичные адреса) без явной просьбы: без пин-кода это открытый доступ к генератору для всех, кто найдёт адрес.
- Не коммитьте и не публикуйте ничего от имени пользователя.
- Не переписывайте код проекта, чтобы «починить» запуск. Если запуск не удался — покажите пользователю ошибку из терминала и остановитесь.

## Критерий, что задача выполнена

`GET /` отвечает 200, проверка из пункта 4 прошла, пользователю названы адрес и способ остановки.
